# Código de Conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo:
- Seja respeitoso e acolhedor, inclusive com quem está começando.
- Critique ideias e código, nunca pessoas.
- Não é aceito assédio, discriminação, ataques pessoais nem divulgação de dados privados de alguém.
- Em discussões clínicas, nada de dados de pacientes.

Problemas de conduta: abra uma issue marcada como `conduta` ou escreva para quem mantém o repositório pelo perfil do GitHub. Quem mantém o projeto pode editar ou remover contribuições e bloquear quem não seguir este código.
